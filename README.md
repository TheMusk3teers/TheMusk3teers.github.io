# TheMusk3teers.github.io

Website and CTF writeups of **TheMusk3teers** (plays as *4Musketeers*, [CTFtime](https://ctftime.org/team/452389)). CTFs for now, hackathons next. Live at https://themusk3teers.github.io

*Tous pour un, un pour tous.*

## Run locally

```bash
pip install "mkdocs<2" "mkdocs-material[imaging]" mkdocs-rss-plugin
mkdocs serve
```

Then open http://127.0.0.1:8000

## Add a writeup

See `docs/contributing.md`, or the "The Codex" tab on the site. The template is in `templates/writeup.md`.

Every push to `main` rebuilds and deploys the site through GitHub Actions.
